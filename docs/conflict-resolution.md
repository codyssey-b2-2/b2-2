# Conflict Resolution Log

> 팀 전체 최소 2회. 최소 1회는 비자명 충돌이어야 합니다.
> - 같은 파일의 같은 hunk(인접 라인)를 서로 다르게 수정
> - 한쪽은 파일 이동/이름 변경/삭제, 다른 쪽은 내용 수정

## 충돌 기록 #1

### 참여자
- 작성자: <name>
- 상대: <name>

### 충돌 유형
- <일반 / 비자명(같은 hunk) / 비자명(이동·삭제 vs 수정)>

### 상황 (What happened)
- 어떤 브랜치/파일에서 충돌이 났는지

### 충돌 내용 (Conflict markers)
```txt
<<<<<<< HEAD
...
=======
...
>>>>>>> feature/...
```

### 해결 과정 (How)
- 선택한 해결 전략(keep both / choose one / refactor)과 이유
- 실제로 수행한 명령 또는 절차

### 결과 (Outcome)
- 최종 병합 결과 요약, 관련 PR/커밋 링크

### 배운 점 (Learnings)
- 다음에 예방하려면 무엇을 할지
